# Air2Screen native sources

This is the source distribution for the native receiver components in the Air2Screen 1.0.0 Microsoft Store package (Windows x64).

- Download `Air2Screen-Native-Sources-1.0.0.zip` from the [v1.0.0 release](../../releases/tag/v1.0.0). No Store purchase is needed to download it.
- The archive contains UxPlay at its pinned upstream commit, the patches used by this release, the build scripts, and third-party notices. UxPlay is licensed under GPL-3.0-or-later.
- [Native runtime source index](native-runtime-sources-1.0.0.md) links to the matching MSYS2 source archives for bundled runtime libraries.
- Use the release's SHA-256 file to check the source archive after downloading it.

The receiver sources and third-party dependencies are covered by their respective licenses and notices.
